# ❤️ Heart Simulator

브라우저에서 바로 실행되는 인터랙티브 **심장 시뮬레이터**입니다. 외부 라이브러리 없이 단일 HTML 파일로 동작합니다.

## 기능

- **뛰는 심장 애니메이션** — 심박 주기에 맞춰 수축/이완하는 심장 그래픽 (Canvas)
- **실시간 ECG 파형** — P–QRS–T 파형을 시뮬레이션하여 스크롤 표시
- **심박수 조절** — 30 ~ 200 BPM 슬라이더
- **프리셋** — 휴식 / 정상 / 운동 / 전력 / 서맥
- **실시간 지표** — RR 간격, 추정 분당 박출량(Cardiac Output), 상태 분류, 누적 박동 수
- **상태 분류** — 서맥 / 정상 / 빈맥 / 위험 빈맥 자동 표시

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

```bash
# 또는 로컬 서버로 실행
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 참고

ECG 파형과 분당 박출량은 교육·시각화 목적의 단순화된 모델이며 실제 의료 진단용이 아닙니다.
