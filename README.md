# ❤️ Heart Simulator (Terminal)

유튜브 쇼츠의 "수학적 하트 그래프 시뮬레이터"를 터미널에서 동작하는 대화형 Python 앱으로 구현한 것입니다.
단일 파일(`heart.py`)이며 **순수 표준 라이브러리(`curses` + `math`)만** 사용합니다. (numpy / matplotlib / PyQt 불필요)

## 수식

하트는 다음 부등식을 만족하는 점 `(x, y)` 의 집합으로 채워집니다.

```
x^2 - |x|*y + y^2 - r <= 0
```

- `|x|` 항 덕분에 **y축 대칭**이 되고, 상단의 굴곡(cusp)과 하단의 뾰족한 꼭짓점이 생깁니다.
- `r` 은 하트의 **크기/면적** 파라미터입니다.
- 곡선은 원점에서 최대 `2*sqrt(r/3) ≈ 1.1547*sqrt(r)` 만큼 위로 뻗습니다 — 화면 스케일 계산의 기준입니다.

빌드업 모드에서는 일반화된 형태를 사용합니다.

```
x^2 - a*|x|*y + b*y^2 - r <= 0
```

- `a=0, b=0` → 수직 띠 (`x^2 <= r`)
- `a=0, b=1` → 원반 (`x^2 + y^2 <= r`)
- `a=1, b=1` → 하트

## 렌더링

- 유니코드 반블록(`▀ ▄ █`)으로 셀당 세로 2서브픽셀을 그려 고밀도로 채웁니다.
- 화면 중앙이 원점 `(0,0)`인 데카르트 좌표계이며, 매 프레임 터미널 크기에서 스케일을 다시 계산해 **리사이즈에 대응**합니다.
- 반블록 서브픽셀이 거의 정사각이므로 x/y 스케일을 동일하게 사용합니다.
- 내부 깊이(`margin = r - 값`, `r`로 정규화)에 따라 **빨강 → 핑크 그라데이션**으로 채색합니다.
  256색 터미널이면 팔레트를 쓰고, 아니면 기본 빨강 + 볼드로 폴백합니다.

## 모드

1. **빌드업 모드** — `b`를 `0→1`(수직 띠 → 원반), 이어서 `a`를 `0→1`(원반 → 하트)로 순차 애니메이션.
2. **파라미터 제어 모드** — `←/→` 로 `r`을 실시간 증감해 하트를 확대/축소. `r`이 최대값에 도달하면 화면을 가득 채우고 상태줄에 `FLOODED`를 표시.

## 조작키

| 키      | 동작                         |
| ------- | ---------------------------- |
| `←` / `→` | 크기(`r`) 감소 / 증가        |
| `b`     | 빌드업 애니메이션 재생       |
| `r`     | 기본 크기로 리셋             |
| `q`     | 종료                         |

하단 한 줄에 상태(`r` 값, `%`, 안내)가 표시됩니다.

## 실행법

```bash
# 기본 실행 (빌드업 애니메이션 후 파라미터 제어 모드)
python3 heart.py

# 빌드업 생략하고 바로 하트 표시
python3 heart.py --no-build

# 초기 크기 / 프레임레이트 지정
python3 heart.py --r 50 --fps 30

# curses 없이 한 프레임만 stdout에 출력 (모양 확인용)
python3 heart.py --ascii --r 30 --cols 80 --rows 30
python3 heart.py --ascii --r 5     # 작은 하트
python3 heart.py --ascii --r 100   # 화면을 넘침(overfill)
```

## 옵션

| 옵션          | 설명                                        | 기본값 |
| ------------- | ------------------------------------------- | ------ |
| `--r`         | 초기 크기 파라미터 `r` (1~100)              | 30     |
| `--no-build`  | 빌드업 애니메이션 생략                      | off    |
| `--fps`       | 초당 프레임 수                              | 30     |
| `--ascii`     | curses 없이 한 프레임을 stdout에 출력       | off    |
| `--cols`      | `--ascii` 출력 가로 크기                    | 80     |
| `--rows`      | `--ascii` 출력 세로 크기                    | 40     |
